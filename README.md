# Udeme Ekanem — Personal Website

Personal portfolio for [Udeme Ekanem](https://uekanem.com), founder-engineer and CTO.

## Local preview

This is a dependency-free static site. Serve the repository root with any local server, for example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Hosting

The site is designed for GitHub Pages and is published from the repository's default branch.
